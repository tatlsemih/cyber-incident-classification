# Veri

Orijinal veri: [Microsoft Security Incident Prediction (GUIDE), Kaggle](https://www.kaggle.com/datasets/Microsoft/microsoft-security-incident-prediction). Eğitim 9.5 milyon, test 4.1 milyon satır (yaklaşık 2.5 GB).

Boyut nedeniyle repoda tekrar üretilebilir rastgele örneklem var (seed 42):

| Dosya | Satır | Kaynak |
|---|---|---|
| `GUIDE_train_sample.csv` | 40.000 | `GUIDE_Train.csv` |
| `GUIDE_test_sample.csv` | 12.000 | `GUIDE_Test.csv` |

Tam veriyle çalışmak için Kaggle'dan indirilen dosyalar bu klasöre konup notebook'taki dosya adları değiştirilebilir.
